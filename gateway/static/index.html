Good to know

  • Gateways run on free hosting tiers around the world. Tervyn tests all of them and picks the fastest; pick another one any time.
  • Sites see the gateway's address, not yours. The gateway can see which sites you open and their content, so avoid banking and other sensitive logins.
  • "Exit" countries route through free public proxies (only on gateways that offer them). They're slower and run by unknown people.
  • For whole-browser protection, use the Tervyn VPN extension.
